# mindlist

Your mindlist saves in Claude and Codex. One install does two things: it connects Claude or Codex to your saves through the mindlist connector, and it adds a skill that knows when your saves can help, finds them, and cites each one it uses.

## Use it

Ask "What did I save about pricing pages?", "Use my saves for this", "Turn my saves on onboarding into a brief", or "What's new in my mindlist?". In Claude, connect it once: Customize, Plugins, mindlist, Connectors, Connect, then sign in with the email code mindlist sends.

## What it reads and never writes

It reads your saves through your own connection: titles, summaries, highlights, tags, your notes, and the full text of a save it uses. It never edits, deletes, tags or shares anything. It moves your "what's new" position after showing you the new saves, and it saves a link only when you name that link and ask. What Claude or Codex reads is handled under your own agreement with Anthropic or OpenAI.

## Data

The skill is text only and runs nothing on your computer. It sends nothing anywhere except your own mindlist connection at mindlist.ai. Each call it makes carries the mark via "skill", so mindlist can count how many people use the skill; mindlist keeps only that count per command and day, never what you asked or what came back.

Privacy: https://mindlist.ai/privacy
