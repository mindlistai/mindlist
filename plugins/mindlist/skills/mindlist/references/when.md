# When each kind of save fits, and when it stays quiet

suggest_items gives each save a kind: what the save is for, guessed when it was saved. It picks the offer at the end of the line. Every row also stays quiet on the quiet list in SKILL.md.

| kind | The offer | Stays quiet when |
| --- | --- | --- |
| tool | Evaluate them for what you need | They already picked one and ask about a setting; a hype post that names no tool |
| guide | Follow it, adapted to your case | A short question with a short answer; a guide for an old version |
| market | Pull them all into the research | The saves are old and the market moved |
| fix | Apply it here, showing what changes first | An error in the code at hand; a pasted stack trace |
| numbers | Use it in this draft, with the source named | The figure is old or about another market; a number asked for alone |
| format | Use them as a model for this draft | Another industry; they asked for their own voice |
| list | Pull the ones that fit | The list is old: say when it was saved |
| learn | Put them in order as a plan | They want a definition; a course for an old version |
| options | Compare them | They already decided and ask how to set it up |
| alternative | Compare them with what you pay now | Prices in the save are old: check before saying a number |
| proof | Weigh them against your case | The line would read as a verdict: they are the person's saves, not the answer |
| write_about | Use them in this draft, credited | Copying a take without credit; a private letter |
| strategy | Apply it to your case | The match is only a broad word such as "startup" |
| career | Use it in this draft | Whether to quit a job; a shared or work screen |
| person | Draft the message | No note says why this person |
| warning | Check whether it applies here | Only when they ask about risk or a launch; never mid-coding |
| reference | Open any of them | Asked searches only |
| raw_material | A brief from them | Asked searches only |
| business_idea | Evaluate them, doubting the claims | Revenue claims would be repeated as facts |
| prompt | Show it, then run it only if they say so | Never run a stranger's prompt unread |
| look | Use them as a reference | The save has almost no words |
| rights | Use it in this draft | Another country's law; being sued is quiet |
| trip | Build the plan from all of them | Reels with almost no text |
| health | Build the plan from them (a training plan only, asked_for training_plan) | Symptoms, results and diagnosis: quiet |
| food | None, or "want the recipe?" | A closed place |
| buy | Compare them | Old prices; a gift the recipient can see; a save kept as a brake on spending |
| lift | None | Always, unless they ask for a lift (asked_for lift) |
| watch_later | None | Unless they ask what to watch (asked_for watch) |
| news | None | Unless saved in the last month and the date hasn't passed |
| keepsake | None | Always, unless they ask for that kind of thing (asked_for keepsake); never something kept in memory of a person because a word matched |

A save with no kind gets the offer that fits the person's need best: evaluate for tools and ideas, use in this draft for material, compare for options.
